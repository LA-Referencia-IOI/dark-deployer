# Historical Material

This directory contains documents produced during earlier design iterations,
diagnostics, proposals and implementation handoffs. They are preserved for
traceability only and are not operational instructions. The canonical current
documentation is:

- [`architecture.md`](architecture.md)
- [`deployer.md`](deployer.md)
- [`operations.md`](operations.md)

When historical material conflicts with code or those documents, the current
CLI, inventory templates and canonical documents take precedence.
